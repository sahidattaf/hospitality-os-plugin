# Hospitality OS Video Production SOP

## Status flow
Discovery Needed → Brief Ready → Script Draft → Internal Review → Client Approval → Production Authorized → In Production → Quality Review → Scheduling Authorized → Scheduled → Publication Authorized → Published → Measured → Archived

## Procedure

1. **Discovery** — collect client, objective, audience, offer, proof, language, channel, CTA, destination, deadline, and approval owner.
2. **Fact gate** — stop when prices, dates, capacity, availability, or claims are unverified.
3. **Script package** — run the master prompt and save the version.
4. **Internal review** — check hook, pacing, factual accuracy, brand voice, and CTA alignment.
5. **Client approval** — record script and language approval before production.
6. **Production authorization** — require an explicit owner gate before generating or editing production assets with external tools.
7. **Production** — generate the draft with the authorized avatar, voice, format, and approved assets.
8. **Quality review** — watch with sound and muted; inspect lip sync, pronunciation, subtitles, safe margins, visuals, music, and CTA.
9. **Scheduling authorization** — require an explicit owner gate naming asset, account, channel, and date/time.
10. **Publication authorization** — require a separate explicit owner gate when publication was not already authorized.
11. **Publication** — test the destination on mobile, publish only to the approved channel, and record the live URL.
12. **Measurement** — capture results after 24 hours, 7 days, and 30 days where relevant.
13. **Learning** — document the winning hook, language, audience, CTA, and next experiment.

## Security
- Never commit API keys or private avatar identifiers.
- Store identity footage and consent records outside public repositories.
- Never create deceptive testimonials or unauthorized impersonations.
- Human or client approval is mandatory before public release.

## Failure routing
- Missing prospecting details → [hospitality-sales-operator](../../hospitality-sales-operator/SKILL.md) or client owner
- Missing event or catering details → [events-catering-operator](../../events-catering-operator/SKILL.md)
- Missing captions or channel packaging → `video-production-operator`; return dated multi-channel calendar requirements to the owner
- Language uncertainty → approved human reviewer
- Broken destination or lead flow → [hospitality-delivery-manager](../../hospitality-delivery-manager/SKILL.md)
- Negative guest situation → [guest-experience-operator](../../guest-experience-operator/SKILL.md)
