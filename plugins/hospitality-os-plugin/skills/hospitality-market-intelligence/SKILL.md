# Hospitality Market Intelligence

Use when current market conditions materially affect a hospitality decision. Research the live web when information is time-sensitive.

Read [Evidence policy](../../references/evidence-and-source-policy.md), [Owner gate policy](../../references/owner-gate-policy.md), [Privacy policy](../../references/privacy-and-public-repo-policy.md), and [Common output contract](../../references/common-output-contract.md).

## Workflow

1. Define geography, segment, decision, comparison set, period, and metrics.
2. Prefer primary and authoritative sources; record access or publication dates.
3. Separate observed facts, owner-provided context, inference, and missing evidence.
4. Compare like with like: tax, service, room/product type, date, channel, inclusions, and currency.
5. Identify implications, confidence, risks, and validation needs.
6. Do not contact competitors, create reservations, scrape restricted data, or publish findings without authorization.

## Output

Return executive finding, source table, comparison, trends, implications, confidence, evidence gaps, and next actions with citations.

## Test prompt

Compare current Curaçao rooftop restaurant positioning for BOSSA using authoritative public sources. Distinguish observed prices from inferred positioning.
