# Evidence and Source Policy

Classify material claims as:

- **Verified:** supported by a current authoritative source
- **Owner-provided:** explicitly stated by the owner but not independently verified
- **Assumption:** a working hypothesis
- **Conflict:** incompatible claims
- **Missing evidence:** required information is unavailable

Do not turn examples, old drafts, images, estimates, or repeated statements into verified facts.

For BOSSA menu work, use `BOSSA Menu Items — Master` as the sole editable source when available. Prices, availability, opening hours, capacity, ingredients, allergens, policies, promotions, staffing, financials, and publication status require current evidence before external use.

If sources conflict, preserve the authoritative record, stop the affected action, and request an owner decision.
