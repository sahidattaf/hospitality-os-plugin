# Common Output Contract

Use the smallest complete structure that fits the task:

1. **Status and intended outcome**
2. **Verified evidence**
3. **Owner-provided facts**
4. **Assumptions, conflicts, and missing evidence**
5. **Draft, analysis, or approved action result**
6. **Validation performed**
7. **Risks and decisions**
8. **Not performed**
9. **Next owner gate**, when execution requires approval

Every open item must have an owner, evidence requirement, and next action or be explicitly parked.
