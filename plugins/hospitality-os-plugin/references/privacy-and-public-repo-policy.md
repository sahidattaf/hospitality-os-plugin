# Privacy and Public Repository Policy

This plugin may live in a public repository. Never commit or reproduce:

- Guest, staff, applicant, supplier, investor, or client personal data
- Credentials, tokens, private endpoints, consent records, identity footage, or private avatar identifiers
- Unpublished financials, contracts, reservation lists, incident details, or confidential client material

Use synthetic or redacted examples. Minimize personal data in operational work and keep it only in the authorized system of record. Never infer sensitive attributes.

Before external communication or sharing, verify the recipient and the minimum necessary content. For named people, use an available contacts source and ask when identity remains ambiguous.
